# ALSKwela A&E 2027 — Elementary LS 5: Pag-unawa sa Sarili at Lipunan

## Deploy via GitHub Pages
1. Create a PUBLIC repository, suggested `alskwela-ls5-pagunawa-reviewer-elementary`.
2. Unzip and upload the individual files in this folder DIRECTLY to the repository root. Do not upload the ZIP as the website and do not nest the files.
3. From Settings > Pages, choose Deploy from branch > main > /(root).
4. Open the HTTPS GitHub Pages URL in Android Chrome, not solely in the Glide in-app browser.
5. Refresh while connected; confirm the application reports that offline files are saved.
6. In Chrome's three-dot menu, choose Install app or Add to Home Screen. Some Android devices offer Create shortcut, which may still open offline if caching succeeded.
7. Switch to airplane mode, close and reopen the home-screen reviewer, start a trial, submit an answer and download a PDF.
8. In ALSKwela Glide, link a reviewer card to the GitHub Pages HTTPS URL via Open Link.

**App name:** Elementary ALS A&E Reviewer LS 5 - Pag-unawa sa Sarili at Lipunan
**Home screen:** Elem A&E LS5 Pag-unawa
**Bank:** 90 original draft questions, 21 competencies, 3 sets of 30. Difficulty: 9 Easy, 15 Moderate, 6 Challenging per set.
**Trial:** Each random trial retains 4 Sarili, 7 Pamilya, 9 Komunidad, 10 Bansa items and all 21 competencies.
**Offline:** All content is embedded in index.html; service worker caches the complete app without external CDNs.
**Privacy:** Progress is on-device only. Teacher receives a report only if the learner shares it.
**PDF:** Native lightweight PDF export is offered; browser Print / Save as PDF preserves original Filipino typography best.

This material is an **independently authored practice assessment**, not the official A&E test. Subject-matter validation, learner piloting, and Android real-device offline verification remain necessary.
